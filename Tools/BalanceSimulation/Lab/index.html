SkillTree · Balance Lab

Самостоятельные симуляции, обучение и повторяемые сравнения. Открой MainScene в Unity в Edit Mode и включи Pipeline. Основные игровые файлы и сохранения инструмент не редактирует.

Настройки эксперимента

Новая модель содержит эвристический prior и ещё не обучена. Проверяй обученную модель на seeds, не использованных при её обучении.

Награда

Повторный фарм, убийства и рост статов сами по себе не награждаются.

Задачи и результаты

Остановка выполняется на ближайшей границе этапа. При возобновлении завершённые кампании сохраняются; незавершённая повторяется с исходного seed. Если игра или симулятор изменились, нужен новый эксперимент.

Парное сравнение

Выбери два завершённых проверочных эксперимента с одинаковыми настройками и seeds. Для сравнения баланса фиксируется модель; для сравнения агентов — версия игры. Обучающие партии не сравниваются как проверки баланса.

Память модели

Ситуация: атрибут / тип урона врага / барьер / регенерация / диапазон этапа. Средний возврат — наблюдение в выбранных траекториях, а не доказанная причинная сила ноды. Смещение — обученная поправка к предпочтению действия.
